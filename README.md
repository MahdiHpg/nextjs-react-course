## 🎯 این مرور چه فرقی با داکیومنت خوندن دارد؟

داکیومنت رسمی انگلیسی، پراکنده و طولانی است. این دوره:
- **فشرده و فارسی** — هر فصل = یک بخش داکیومنت، خلاصه و نکته‌محور
- **با مقایسه و تله‌ها** — چیزهایی که داکیومنت می‌گوید، ولی در عمل باعث خطا می‌شوند
- **تمرین با جواب** — برای اینکه «خوانده» نشوی، «بلد» شوی
- **لینک منبع رسمی هر فصل** — برای عمیق‌شدن هرجا خواستی
